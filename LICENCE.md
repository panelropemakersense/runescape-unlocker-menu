## 🧩 About

**RuneScape Companion** is a curated list of RuneScape open-source tools:

- **Overlays** — on-screen helpers, layout notes, tile markers, interface switcher
- **Quality-of-Life Helpers** — skill catalog, gear manager, overlay notes

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Tile Markers — practice from any location
- Show Hitboxes — visualize combat hitboxes
- Replay Notes — record and review skilling runs
- Playback Speed — adjust overlay playback for study (0.1x to 5x)

### Wallhack
- Gear Catalog — browse gear, colors, capes, cosmetics
- Custom Skin Notes — organize player outfits
- Solid Tile Trail — improved tile visibility

### Aimbot
- Training Mode Notes — segment study on any layout
- Camera Control — manually switch view angle mid-session
- Input Buffer Notes — chain complex maneuvers in the client
